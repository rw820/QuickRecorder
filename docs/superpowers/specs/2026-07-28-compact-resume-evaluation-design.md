# 简历初评精简与刷新设计

## 目标

让简历初评更适合面试前快速浏览，并能随时重新生成。

## 输出结构

- 总评、优势、劣势、风险四部分分别不超过 50 个字符。
- 每部分可以包含一到三句，不限制必须是一句话，但只保留关键结论。
- 新增“建议问题”，固定生成 5 个简短、可直接提问的问题。
- 本次只精简简历初评；面试结束后的最终评价保持原有详细格式。

## 长度保障

同时使用两层约束：

1. 在模型提示词中明确字数、结构和问题数量。
2. 在本地解析并规范模型输出，超长内容截短，问题只保留 5 个。

这样即使模型偶尔不遵守格式，界面也不会再次显示大段内容。

## 刷新功能

在“简历初评”标题旁增加“刷新评价和问题”按钮。点击后：

1. 使用已保存的简历文本重新调用当前配置的模型。
2. 显示刷新中状态，避免重复点击。
3. 成功后覆盖本地初评文件并立即更新界面。
4. 失败时保留原评价，并显示错误提示。

## 界面

初评按五块展示：总评、优势、劣势、风险、建议问题。建议问题使用编号列表展示 5 条。
