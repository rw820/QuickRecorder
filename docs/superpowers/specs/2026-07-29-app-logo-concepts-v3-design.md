# 面试助手 Logo 概念设计 V3

## 目标

在 V2 基础上生成四张不重复的新参考图，同时覆盖直观功能表达和抽象品牌表达。

## 统一风格

- 深灰色背景，主体使用单一蓝色，最多加入少量白色。
- 线条比 V2 略细，采用连续平滑曲线、圆角和圆形端点。
- 以扁平图形为主，仅保留很轻的层次，不使用明显 3D、强阴影或光晕。
- macOS 圆角方形构图，主体居中，留白充足，小尺寸可辨识。
- 不使用文字、中文、完整单词、水印、紫色、橙红色、星光或复杂装饰。

## 四个方向

### E：倾听

极简耳朵轮廓与一条对话弧线结合，直观表达听取候选人回答。

### F：问答

两个圆润重叠的对话气泡配合少量圆点，表达面试问答。

### G：声音 M

使用一条连续流畅的声波曲线隐约形成字母 `M`，增强品牌感。

### H：聚焦评价

两个相对圆弧围绕中心圆点，表达观察、聚焦和评价。

## 输出

- 分别生成 E、F、G、H 四张独立正方形参考图。
- 本轮只用于比较和选择，不替换应用现有图标。
