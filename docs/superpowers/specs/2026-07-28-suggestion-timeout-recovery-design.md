# 追问建议超时恢复设计

## 目标

减少实时追问因 Codex 响应较慢而直接失败的情况，同时避免请求堆积。

## 方案

- 单次追问生成超时由 20 秒提高到 30 秒。
- 仅当错误为超时时，自动重试一次；其他错误不重试。
- 重试期间保留上一次成功生成的问题，不清空界面。
- 沿用现有单任务限制，同一时间只生成一组追问，避免并发堆积。
- 第一次超时不显示失败；第二次仍失败后再显示错误提示。

## 验收

- 第一次调用超时、第二次成功时，界面正常显示新问题且不显示失败。
- 连续两次超时时，只重试一次并显示失败提示。
- 非超时错误不重试。
- 现有追问在新请求失败或重试期间保持可见。
