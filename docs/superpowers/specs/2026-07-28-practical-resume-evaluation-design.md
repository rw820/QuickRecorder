# 简历初评内容优化设计

## 目标

简历初评保持易读，同时提供更多与候选人经历和岗位匹配有关的实际判断。

## 内容规则

- 总评、优势、劣势、风险每部分控制在 60～100 个字符。
- 每部分可以包含多句话，不使用列表。
- 删除“仅为简历初评”“待面试验证”“简历声明”等重复套话。
- 总评重点写岗位匹配与经历结构。
- 优势重点写项目规模、业务领域、职责或可迁移能力。
- 劣势重点写岗位能力缺口和简历中缺少的关键证据。
- 风险重点写成果归因、角色边界、时间线或能力深度等具体疑点。
- 建议问题继续固定生成 5 个，不改变现有展示和刷新方式。

## 长度保障

提示词要求模型输出 60～100 个字符。本地格式化器清理套话并将每部分限制在 100 个字符以内，避免模型输出重新变长。

模型偶尔输出不足 60 个字符时保留原文，不在本地拼接空泛内容；后续点击刷新可以重新生成。

## 范围

只调整简历初评，不改变实时面试建议和面试结束后的最终评价。

## 验证

- 自动测试确认提示词包含新字数与禁用套话要求。
- 自动测试确认本地结果不超过 100 个字符且套话被清理。
- 重新构建、安装并打开应用，使用刷新按钮生成新内容。
