# 可视化评价规则设计

## 目标

在面试助手中增加“评价规则”页面，让用户看清简历初评和面试评价的生成流程，并能维护评分、结论阈值、逻辑检查、输出板块、字数限制和完整提示词。配置只保存在本机；保存失败时继续使用上一次有效规则。

## 已确认范围

- 同时支持“面试评价”和“简历初评”。
- 默认使用结构化编辑器，高级模式支持编辑完整提示词。
- 流程以“输入材料 → 证据与逻辑检查 → 评分 → 结论判断 → 输出结构”展示。
- 支持恢复默认、预览最终提示词、保存并启用。
- 旧评价保持原样；历史记录重新生成时才使用当前规则。

首版不做云同步、多人协作、岗位规则库和多版本历史列表，只保留当前配置、默认配置及上一次有效配置。

## 界面

首页顶部增加“评价规则”按钮，打开独立 sheet。

规则页顶部包含“恢复默认”“查看最终提示词”“保存并启用”。页签分为：

1. 面试评价
2. 简历初评
3. 高级提示词

结构化页面左侧是规则导航，中间是评价流程图，右侧是所选节点的编辑表单。评分维度和输出板块支持新增、删除、排序；系统必需节点会锁定删除操作，但说明文字、分值和内容限制可以修改。

高级提示词页直接编辑完整模板。模板变量采用：

- `{{transcript}}`：面试逐字稿，仅面试模板必需。
- `{{resume}}`：简历文字，简历模板必需；面试模板可选。
- `{{customRequirement}}`：本次手工刷新要求。
- `{{outputContract}}`：由结构化规则生成的输出格式，两个模板都必需。

## 规则模型

`EvaluationRulesConfiguration` 是本机配置根对象，包含版本号、面试规则和简历规则。

面试规则包含：

- 证据约束与禁用信息说明。
- 逻辑检查项列表。
- 评分维度：稳定 ID、名称、满分、评价重点、理由字数。
- 结论阈值：建议通过最低分、保留复核最低分。
- 输出板块：稳定 ID、标题、说明、最大条数、最小/最大字数、是否必需。
- 完整高级提示词模板。

简历规则包含：

- 评价原则。
- 输出板块及顺序。
- 建议问题数量。
- 完整高级提示词模板。

系统默认规则与当前硬编码规则完全等价。评分维度满分合计必须为 100。

## 必需结构与可编辑边界

面试评价的“结论、综合评分、分项评分”是系统必需板块，不能删除；逻辑分析、总评、优势、劣势、风险可以调整顺序、说明和限制，也可增加普通板块。简历初评至少保留一个总评板块和一个建议问题板块。

板块使用稳定 ID 识别，标题可以维护。解析和界面不再依赖写死的中文标题，而是读取本次评价保存的规则快照。

## 保存与校验

配置目录：

`~/Library/Application Support/InterviewAssistant/EvaluationRules/`

- `current.json`：当前启用规则。
- `last-valid.json`：保存新规则前的上一次有效规则。

保存前检查：

- 评分维度名称和 ID 唯一，分值为正数，总和为 100。
- 建议通过阈值高于保留复核阈值，且都在 0 至 100。
- 必需板块存在，板块 ID 和标题不重复。
- 最小字数不大于最大字数，条数大于 0。
- 高级提示词包含对应的必需变量和 `{{outputContract}}`。

校验失败不写文件，界面显示具体错误。读取文件失败时自动使用 `last-valid.json`；两者都不可用时使用内置默认规则。

## 生成与解析

`EvaluationPromptComposer` 使用规则生成提示词。结构化模式生成业务指令和输出合同；高级模式替换完整模板中的变量。两种模式都使用同一个输出合同，保证生成结果可解析。

`InterviewEvaluationScorecard` 和评价板块解析器接收规则快照，不再写死五个维度和标题。模型返回结果必须通过当前规则校验后才能替换旧评价。

每次成功生成时保存规则快照：

- 面试场次：`evaluation-rules.json`
- 当前简历：`resume-evaluation-rules.json`

历史记录显示旧评价时优先读取快照；没有快照的旧记录使用内置默认规则。历史记录点击重新生成后，使用当前规则，并仅在生成和解析成功后替换评价及规则快照。

## 错误处理

- 编辑过程只修改草稿，不影响当前启用规则。
- 保存校验失败：保留草稿并指出字段，不切换规则。
- 模型输出不符合新结构：保留旧评价，显示“评价格式不符合当前规则”。
- 配置文件损坏：回退到上一次有效规则或默认规则。
- 恢复默认只修改草稿，仍需点击“保存并启用”。

## 测试

- 默认规则与现有提示词、评分和评价结构等价。
- JSON 保存、读取、损坏回退和恢复默认。
- 分值、阈值、板块、字数和模板变量校验。
- 自定义维度、标题、顺序及新增板块的提示词生成与解析。
- 无规则快照的旧评价兼容。
- 历史重新生成成功时更新快照，失败时保留旧评价和旧快照。
- SwiftUI 页面编译、按钮入口和基本编辑状态。
