# 面试助手 Logo 概念设计

## 目标

为“面试助手”生成三版 macOS 应用图标参考图。用户选定方向后，再制作并安装正式图标。

## 共同要求

- macOS 圆角方形应用图标构图。
- 不使用文字、字母、人物照片或复杂小细节。
- 主体居中，轮廓清晰，在小尺寸下仍易识别。
- 风格简洁、现代、专业，适合个人内部效率工具。
- 本轮只生成参考图，不修改应用资源。

## 三个方向

### 方案 A：蓝色专业版

使用蓝色系，对话气泡与对勾组合。表达面试沟通、记录和评价，整体稳重可靠。

### 方案 B：蓝紫 AI 版

使用蓝紫渐变，声波与简洁星光组合。表达本机录音、流式转写和智能建议，科技感更强。

### 方案 C：橙红洞察版

使用橙红色系，抽象人物轮廓与聚焦框组合。表达候选人观察、分析和面试洞察，视觉更醒目。

## 输出

分别生成三张正方形参考图并在对话中展示，标注为 A、B、C。参考图本身不放方案名称或其他文字。
