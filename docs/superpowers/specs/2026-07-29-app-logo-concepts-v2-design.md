# 面试助手 Logo 概念设计 V2

## 目标

生成四张新的 macOS 应用图标参考图，比上一轮更克制、更平滑。

## 统一风格

- 深灰色背景，主体使用单一蓝色，最多加入少量白色。
- 不使用彩虹渐变、紫色、橙红色、星光或复杂装饰。
- 图形轮廓采用连续圆滑曲线，端点和转角全部圆润。
- 轻微层次感即可，避免厚重 3D、强阴影和高亮光晕。
- macOS 圆角方形构图，主体居中，留白充足。
- 不放文字、中文、完整单词或水印。
- 小尺寸下仍能识别。

## 四个方向

### A：对话声波

圆润对话气泡与简化声波结合，突出录音、转写和沟通。

### B：双人交流

两个极简人物轮廓通过一条柔和弧线连接，突出面试交流。

### C：文档洞察

圆角文档轮廓与一条流畅波形结合，突出记录、分析和评价。

### D：抽象 i

用圆点与连续弧线构成抽象小写 `i`，同时隐约形成对话气泡，强调品牌感。

## 输出

- 分别生成 A、B、C、D 四张独立正方形参考图。
- 本轮只用于比较和选择，不替换应用现有图标。
