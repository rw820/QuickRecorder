# 历史记录查询与 Logo 调整设计

## 目标

增加可搜索的历史面试记录入口，同时把当前“声音 M”应用图标改为白底、蓝色粗线版本。

## 历史记录

### 入口与布局

- 主界面顶部增加“历史记录”按钮。
- 点击后打开双栏弹窗，不改变当前面试页面。
- 左侧为搜索框和历史场次列表，按时间从新到旧排列。
- 右侧显示选中场次的评价、逐字稿和录音文件。

### 场次信息

每条历史记录包含：

- 面试时间。
- 候选人或简历名称；旧记录没有名称时显示日期。
- 最终评价内容。
- 逐字稿内容。
- 候选人录音 `system.caf`。
- 面试官录音 `microphone.caf`。
- 原始场次文件夹。

新场次复制 `resume-metadata.json` 到场次目录，用于保留原始简历文件名。旧场次缺少元数据时继续正常显示。

### 搜索

关键词不区分大小写，搜索以下内容：

- 日期和场次名称。
- 简历文件名及简历文字。
- 最终评价。
- 逐字稿。

空关键词显示全部记录。

### 操作

- 查看完整评价。
- 查看完整逐字稿。
- 使用系统默认播放器打开候选人录音或面试官录音。
- 在访达中打开该场次文件夹。
- 缺少评价、逐字稿或录音时显示“未记录”。
- 本版不提供删除功能。

## 组件

### `InterviewHistoryStore`

负责扫描 Sessions 目录、解析日期、加载文字和录音路径、建立可搜索的 `InterviewHistoryRecord` 列表。单个损坏场次不影响其他记录。

### `HistoryBrowserView`

负责搜索、列表选择、详情切换和文件打开。默认选择最新记录。

### `MainView`

只负责显示“历史记录”入口和弹窗，不承担文件解析。

## Logo

- 保留 V3 第三个“声音 M”的主体轮廓。
- 背景改为纯白或接近纯白。
- 主体使用单一蓝色。
- 蓝色线条比当前版本明显加粗，端点保持圆形。
- 不使用文字、复杂渐变、强阴影或额外装饰。
- 生成新 PNG 和标准多尺寸 `AppIcon.icns`，替换当前图标资源后重新签名安装。

## 错误处理

- Sessions 目录不存在时显示空状态。
- 单个文件读取失败时该字段显示“未记录”，其他内容仍可查看。
- 打开录音失败时在历史弹窗中显示简短错误。

## 验收

- 能看到现有历史场次，并按时间倒序排列。
- 能通过评价或逐字稿中的关键词筛选场次。
- 能查看评价、逐字稿，打开两个录音和场次文件夹。
- 旧场次缺少简历元数据或录音时不会崩溃。
- 新图标为白底、蓝色粗线“声音 M”，应用签名和录音权限保持有效。
